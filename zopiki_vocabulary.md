## HOW TO READ THIS TABLE

- **IPA:** Approximate International Phonetic Alphabet pronunciation
- **Category:** the word's grammatical/semantic category
- **Status:** "Established [session]" = locked in; do not alter spelling or meaning

---

## KEY PHONOLOGICAL RULES (summary — see 7-A canonical_facts.md for full detail)

- **z** is always /z/ (voiced, as in "zone") — never /s/
- **kk** = geminate velar stop; occurs only word-finally; retained in *Zupakk* as a historicism
- **ch** = always /tʃ/ (as in "church")
- **tl** (word-final) = relational nominalizer; pronounced as syllabic lateral /ɫ/ by native speakers
- **é** = long /eː/ vowel (historicism in *Pequeé* only)
- **Three vowels only:** /a/, /i/, /u/ — no /e/ or /o/ in native Zopikí roots
- **No tones; no ejectives; no uvulars**
- **Stress:** penultimate by default; final when that syllable has a long vowel

## SECTION G: MORPHEME REFERENCE (SUFFIXES AND PREFIXES)

| Morpheme | Type | Meaning / Function | Example | Session |
|---|---|---|---|---|
| **-ya** | Collective suffix | "all of, the gathering of" | *Kanatl-ya* = the council of all chieftains | 1-A / 7-A |
| **-ki** | Plural suffix | Regular plural | *Nakati-ki* = speakers/heralds | 7-A |
| **-chi** | People-of / agent collective | "people of, children of" | *Tupana-chi* = children of the summit | 1-A / 7-A |
| **-zu** | Distributive plural | "each of, individually" | *Kanatl-zu* = each chieftain | 7-A |
| **-tl** | Relational nominalizer | "the one who embodies / stands for" | *kana-tl* = kanatl (embodiment of authority) | 1-A / 7-A |
| **-na** | Locative / Genitive | "at / in / of" | *Zupakk-na* → Zoopaná | 7-A |
| **-ku** | Intensive / augmentative (also "western," "great") | "great, high, western" | *tupana-ku* = great summit | 7-A |
| **-n** | Augmentative | "great, large" | *mara-n* → marán | 7-A |
| **-ti** | Agentive person suffix | "the one who does" | *naka-ti* → nakati | 7-A |
| **-m** | Echo / repetition marker | "re-sounding, memory" | *naka-m* → nakam | 7-A |
| **-pa** | Ergative case | Subject of transitive verb | *kanatl-pa* (chieftain acting) | 7-A |
| **-pu** | Accusative case | Direct object | *maran-pu* (river as object) | 7-A |
| **-chi** | Instrumental case | "by means of, through" | *kati-chi* (by the cord) | 7-A |
| **-ka** | Ablative case | "from, away from" | *maran-ka* (from the river) | 7-A |
| **i-** | Completive aspect prefix | Action completed | *i-naka-na* (spoke, finished) | 7-A |
| **a-** | Continuative aspect prefix | Action ongoing | *a-naka-ku* (will speak, ongoing) | 7-A |

## NOTES FOR FUTURE SESSIONS

1. **No new Zopikí words should be invented without checking this register first.** If you need a new word, derive it from existing roots using the morpheme system above.
2. **The three-vowel constraint is strict:** /a/, /i/, /u/ only. If a proposed word contains /e/ or /o/, it must be explained as a loanword or a historical vowel-merger form (like *Pequeé*).
3. **No ejectives, no uvulars, no tones.**
4. **The -tl suffix** is a relational nominalizer. It should only be used on roots that "embody" a concept, not on random words.
5. **Consult the 7-A canonical_facts.md** for the full grammar sketch before writing Zopikí sentences.
