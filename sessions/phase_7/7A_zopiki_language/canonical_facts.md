## SECTION 1: LANGUAGE FAMILY AND TYPOLOGICAL CLASSIFICATION

### 1.1 Classification

**Zopikí** (*Zupakí* in the language itself; Spanish: *el zopikí*) is classified as a **linguistic isolate** — a language with no demonstrated genealogical relationship to any other known language family. This isolate status has been maintained by the consensus of academic linguistics since the first systematic study by **Dr. Eugenio Ríos-Beltrán** of the Universidad Nacional de Zoopaná in 1947, though it remains a subject of ongoing scholarly debate.

**Proposed affiliations (none confirmed):**

- **The Maranic Hypothesis:** The most persistent minority view, proposed by the Zoopan linguist **Dr. Fortunata Yahuar Quispe** (USO, Cerro Verde; b. 1962) in her 2003 monograph *El zopikí y sus vecinos: hacia una familia marán*, argues that Zopikí, along with two extinct languages documented in colonial sources from the Tucareño highlands (Proto-Tucareño fragments) and the Andean piedmont (Esterol, spoken by a community that vanished by 1700), constitute a "Maranic family" of three related languages. The hypothesis is accepted by a minority of specialists in South American linguistics; the Zoopan academic mainstream regards it as unproven but worth continued investigation.

- **Quechuan structural affinity:** Multiple scholars have noted that Zopikí shares typological features with Quechuan languages (agglutinative morphology, SOV word order, a three-vowel system, evidentiality markers, relational noun suffixes). This is not disputed. The disagreement is over whether these affinities represent ancient genetic relationship, ancient contact borrowing, or independent parallel development. The mainstream view is ancient contact borrowing, consistent with the documented Inca influence on western Zopikí communities in the late 15th century (per session 1-A).

- **Nahuatl-like features:** The **-tl** nominal suffix (visible in *Marantl*, *Kanatl*, *Nakatl*, *Pachatl*) has sometimes been compared to the Nahuatl absolutive suffix. This comparison is rejected by all serious specialists: the Zopikí -tl is a grammaticalized relational nominalizer, historically derived from the root *tila* ("to stand before / to embody"), not cognate with Nahuatl morphology. The resemblance is typological coincidence arising from similar phonological environments in which a /t/ + /l/ cluster becomes grammatically productive.

**Official classification:** Isolate. Zopikí is listed as such in the *Ethnologue*, the *Glottolog*, and the *Atlas of the World's Languages in Danger* (UNESCO).

### 1.2 Typological Profile

| Feature | Zopikí |
|---|---|
| **Morphological type** | Agglutinative |
| **Word order** | SOV (Subject–Object–Verb) with some pragmatic flexibility |
| **Head position** | Head-final (consistent with SOV): postpositions, genitive before noun, relative clauses before head noun |
| **Case system** | 8 cases, all suffixed |
| **Number** | Singular unmarked; plural -ki; collective -ya; distributive -zu |
| **Verb agreement** | Verbs agree with both subject and object via suffixed portmanteau morphemes |
| **Tense** | 4 tenses: recent past -na, distant past -ma, present/habitual -tl (relational present), future -ku |
| **Aspect** | Completive vs. continuative, marked with prefixes |
| **Evidentiality** | 3-way: direct witness -pa, inference -chi, reportative -zu |
| **Tone** | None — Zopikí is not a tonal language |
| **Vowel harmony** | Partial: high vowels /i/ and /u/ trigger harmony in certain suffixal environments |

## SECTION 2: PHONOLOGY

### 2.1 Consonant Inventory

Zopikí has 18 consonants. There are no ejectives and no uvulars — features that distinguish it from many Andean languages (notably Quechua and Aymara). This absence is consistent with its lowland river-basin origin; ejectives are characteristic of high-altitude highland languages.

| | Bilabial | Alveolar | Palatal | Velar | Glottal |
|---|---|---|---|---|---|
| **Stops** | p | t | | k | |
| **Affricates** | | | ch /tʃ/ | | |
| **Fricatives** | | s, z /s, z/ | | | h |
| **Nasals** | m | n | | | |
| **Laterals** | | l | | | |
| **Rhotics** | | r /ɾ/ | | | |
| **Glides** | w | | y /j/ | | |

**Notes:**
- /z/ is voiced in all environments: always pronounced as in English "zone," never as /s/. This is the phoneme that gives the country its name (Zupakk → Zoop).
- /kk/ (geminate/long velar stop) occurs word-finally and medially; it is a distinct phoneme, not merely doubled /k/. In the word *Zupakk*, the final geminate /kk/ historically marked locative completion — "the place fully realized as the confluence." In modern speech and in all Zopikí written from 1998 onward, final *-kk* is retained as a spelling convention honoring the historical form.
- /ch/ is always the affricate /tʃ/ as in "church," never just /ʃ/.
- /r/ is a tap /ɾ/, never a trill.
- /h/ is a glottal fricative, pronounced in all positions including word-finally (rare).

### 2.2 Vowel Inventory

Zopikí has a **three-vowel system**: /a/, /i/, /u/. This is the same system found in Quechua and Aymara — consistent with the ancient contact hypothesis.

| Vowel | Description | Example |
|---|---|---|
| /a/ | open central | *marán* (river), *kanatl* (chieftain) |
| /i/ | close front | *Zopikí* (the language itself), *inti* (sun/day) |
| /u/ | close back | *Zupakk* (confluence), *tupana* (festival) |

**Long vowels:** Vowel length is phonemic in a small number of minimal pairs. Long vowels are written with an acute accent + the vowel letter: *á*, *í*, *ú*. In existing canonical words, *Pequeé* illustrates a long /e:/ — RECONCILIATION NOTE: The *é* in *Pequeé* represents a historical vowel merger. The original form was *Pekuí* ("high ford/crossing") in which the /u/ and /i/ vowels contracted across the intervening consonant when the word moved from Tupanachi dialect (highland Zopikí) to the prestige lowland dialect. The contracted long mid vowel is represented in colonial Spanish orthography as *-eé* and the modern Zopikí standard retains this spelling as a historicism. In spoken Zopikí, *Pequeé* is pronounced /peˈkeː/.

### 2.3 Phonotactics and Syllable Structure

- **Syllable structure:** (C)V(C) — consonant clusters are limited to the coda position and to the word-final geminate *-kk*
- **Preferred word shape:** Zopikí roots are typically bisyllabic: *ma.rán*, *ka.natl*, *in.ti*, *zu.pakk*
- **The -tl cluster:** The word-final *-tl* cluster (as in *Kanatl*, *Marantl*, *Nakatl*, *Pachatl*) is a special morphophonological unit: historically, *-tl* = the relational nominalizer *tila* ("the one who stands for / embodies") contracted to a suffix. In pronunciation: /tl/ is realized as a syllabic lateral in native speaker speech — /ˈkanatɫ/, approximately. In Spanish-influenced pronunciation, it is often /ˈkanal/ or /ˈkanat/ (with the /l/ or /t/ dropping). The standard modern orthography retains the full *-tl* cluster.
- **Stress:** Penultimate in most words; final in words with a long vowel in the final syllable (*marán* = stress on final syllable because the /á/ is long).

## SECTION 3: GRAMMAR SKETCH

### 3.1 Noun Morphology

Zopikí nouns carry suffixes for number, case, and relational status. The basic noun stem is unmarked for number; singular is the default.

**Number suffixes:**
- **-ki** = plural (*kanatl-ki* = chieftains; *nakati-ki* = speakers)
- **-ya** = collective ("all of, the gathering of") (*kanatlaya* = the council of all chieftains — from *kanatl* + *-ya*)
- **-zu** = distributive ("each of, each one") (*kanatl-zu* = each chieftain individually)

**Case suffixes (selected):**
| Case | Suffix | Meaning | Example |
|---|---|---|---|
| Absolutive | (unmarked) | Subject of intransitive verb; citation form | *kanatl* |
| Ergative | -pa | Subject of transitive verb | *kanatl-pa* (the chieftain [who acts on something]) |
| Accusative | -pu | Direct object | *kanatl-pu* (the chieftain [as direct object]) |
| Genitive | -na | Of/belonging to | *Zupakk-na* (of the confluence) |
| Locative | -na | At/in/to | *Zupakk-na* (at the confluence) — genitive and locative are homophonous; context disambiguates |
| Instrumental | -chi | By means of / through | *kati-chi* (by means of the cord) |
| Ablative | -ka | From / away from | *maran-ka* (from the river) |
| Comitative | -ku | With / together with | *kanatl-ku* (together with the chieftain) |

**Note on -na:** The locative/genitive suffix *-na* is highly productive in place-name formation: *Zupakk-na* → colonial Spanish rendering → *Zoopaná* (the city "at the confluence"). This is the etymology of the capital's name.

### 3.2 Verb Morphology

Zopikí verbs are agglutinative, built from a root with prefixes for aspect and suffixes for tense, evidentiality, and agreement.

**Tense suffixes:**
- **-na** = recent past (within living memory or the current season)
- **-ma** = distant past (mythological time, ancestral time, or anything beyond living memory)
- **-tl** = present/habitual/relational (the most common form; appears as a nominalizer when on nouns)
- **-ku** = future

**Aspect prefixes:**
- **i-** = completive (action completed)
- **a-** = continuative (action ongoing)

**Example verb conjugation — root *naka-* (to speak/say):**

| Form | Zopikí | Gloss |
|---|---|---|
| Habitual (I speak) | *naka-tl-imi* | speak-PRES-1SG |
| Past (I spoke, recently) | *i-naka-na-imi* | COMPL-speak-PAST-1SG |
| Past (in ancestral time) | *i-naka-ma-imi* | COMPL-speak-DIST.PAST-1SG |
| Future (I will speak) | *a-naka-ku-imi* | CONT-speak-FUT-1SG |

**Subject agreement suffixes (selected):**
| Person | Suffix |
|---|---|
| 1SG (I) | -imi |
| 2SG (you) | -itu |
| 3SG (he/she/it) | -ita |
| 1PL (we) | -imi-ki |
| 3PL (they) | -ita-ki |

### 3.3 Adjective Position

In Zopikí, **adjectives precede the noun they modify** — head-final, consistent with the SOV typology. This is visible in the established vocabulary:

- *Inti-Zupaka* = "sun [of] confluence-people" (literally: sun + confluence-people; the first element modifies the second)
- *Kanatl-pela* = "golden chieftain" — in the compound, *pela* (golden) precedes/modifies the nominal idea of chieftain authority

In full adjective phrases: *pela kanatl* = "the golden chieftain" (free adjective phrase); *kanatl-pela* = "golden-chieftain" (fixed compound/title). The compound form freezes adjective-noun order with a binding hyphen in the standard orthography.

### 3.4 Sample Sentences

**Sentence 1:**
> *Zupakk-na imi-pa maran-pu itupana-tl.*
>
> confluence-at I-ERG water-ACC offer-PRES
>
> "At the confluence, I offer water." (ritual formula used at the Bendición de las Aguas)

**Sentence 2:**
> *Kanatl-pa kanatlaya-pu a-naka-ku-ita.*
>
> chieftain-ERG council-ACC CONT-speak-FUT-3SG
>
> "The chieftain will speak to the council."

**Sentence 3:**
> *Inti-Zupaka-pa pacha-pu i-tika-ma-ita.*
>
> Sun.of.Confluence-ERG earth-ACC COMPL-give.fruit-DIST.PAST-3SG
>
> "Inti-Zupaka gave fruit to the earth." (from the *Tupana Inti-kama* oral epic; opening line)

## SECTION 5: PLACE NAME ETYMOLOGIES

### 5.1 Primary Place Names of Zopikí Origin

**Zoopaná (capital city)**
- Zopikí original: *Zupakk-na*
- Etymology: *zupakk* (confluence, "where rivers run together") + *-na* (locative suffix, "at/in")
- Meaning: "at the confluence"
- Development: The Zopikí settlement at the main river confluence was called *Zupakk-na* by its inhabitants ("we live at the confluence"). Spanish colonists heard this as *Zupacana*, then *Zupacná*, then *Zoopana*, and finally stabilized as *Zoopaná* (with Spanish accent on the final syllable) by the mid-18th century. The name thus preserves both the root *Zupakk* (which also gives Zoop its national name) and the locative *-na*.

**Zoop (the country)**
- Zopikí original: *Zupakk*
- Etymology: "where rivers run together" — the confluence
- Development: Spanish colonists rendered the word variously as *Zupac*, *Zupak*, *Zopa*, *Zoop*. By the late 1700s, *Zoop* was the common Spanish-language form for the colonial province of the Río Marán basin. The geminate *-kk* was lost in Spanish pronunciation; the /u/ shifted toward /oo/ in the Spanish phonological environment.

**Río Marán**
- Zopikí original: *Marán* (from *mara-n*)
- Etymology: *mara* (water, to flow) + *-n* (augmentative suffix)
- Meaning: "the great flowing water," "the great river"
- Notes: The Zopikí Confederation used *marán* as the proper name of their central river and also as a common noun meaning "the largest river in a watershed." In Zopikí, *mara* alone means "water/flowing," while *marán* specifically denotes a major navigable river. The deity *Marantl* (*mara-n-tl*) is "the one who embodies the great river" — the river-spirit.

**Río Pequeé**
- Zopikí original: *Pekuí* (highland dialect *Pequeéka* variant: *Pekwé*)
- Etymology: *peké* (crossing, ford) + *-í* (highland marker, "upward/above")
- Meaning: "the high ford" / "the upper crossing"
- Development: In the Pequeéka highland dialect, the word was *Pekwé*; in the lowland prestige dialect, the /w/ and /i/ contracted when adjacent to the stressed /e/: *Pekwé* → *Pekwéi* → *Pequéi* → the long vowel *Pequeé* /peˈkeː/. Spanish orthography rendered this contraction as the double-e spelling *Pequeé*. The name refers to the fact that the Río Pequeé was historically crossed at a specific high ford in the Cordillera Pequeé — the same pass that the Inca used as a trade route and that Diego de Aranduy used to enter Zoop in 1538.

**Cordillera Tupanaku**
- Zopikí original: *Tupanaku*
- Etymology: *tupana* (festival, meeting, great summit) + *-ku* (great/high/intensive suffix)
- Meaning: "the great summit" / "place of the great meeting"
- Notes: The dual meaning is intentional. The Kanatlaya traditionally held its highest festivals in the foothills of this range; the mountain peaks themselves were considered dwelling places of Inti-Zupaka. The Spanish name "Cordillera Tupanaku" preserves the Zopikí word essentially intact.

**Confluencia (town at the Río Pequeé / Río Marán junction)**
- The town of Confluencia (San Bartolomé province) sits at the point the Zopikí called *Bartomac* — "the river fork" (root of the community name *Bartomaca*). The Spanish name "Confluencia" (confluence) is a calque translation of the Zopikí place concept, not a survival of the Zopikí word. However, the community name *Bartomaca* ("people of the river fork") is of Zopikí origin: *barto* (fork/branching) + *maca* (place/community).

**Cerro Verde**
- A Spanish descriptive name (green hill/mountain); not of Zopikí origin. However, the Zopikí name for the highland area was *Tupanachi Kur* ("the heights of the highland people"), referring to the Tupanachi community's highland territories. The Inca-influenced highland communities sometimes used the Quechua loanword *Quri Urqu* (golden mountain) for the same area, which is unrelated to the Spanish *Cerro Verde*.

**Candelaria (province and city)**
- The province name is Spanish (candle/Candlemas feast). The Zopikí community *Kanelaya* ("people of the warm water/northern stream") gives the region a pre-colonial identity; *Kanelaya* is not the etymological root of *Candelaria* (which is purely Spanish ecclesiastical), but the phonological resemblance is noted in Zoopan place-name scholarship and may have reinforced the Spanish acceptance of the name.

**Salar de Tupanaku**
- Named for the Cordillera Tupanaku, applying the mountain range name to the highland salt flat within the range's territory. Zopikí origin via *tupana* + *-ku* (see Cordillera Tupanaku above).

### 6.3 Age Distribution

The age distribution of fluent speakers reflects the history of language suppression and revival:

- **65+:** The most densely fluent cohort; approximately 38% of all fluent speakers; the primary carriers of the oral literary tradition
- **45–64:** Approximately 29% of fluent speakers; the generation that came of age during the Years of Lead; many deliberately did not transmit Zopikí to children during the worst years (1974–1981) for fear of social targeting
- **25–44:** Approximately 20% of fluent speakers; the first generation to benefit from the 1994 recognition and the LEIB bilingual programs; includes many revivalist speakers who relearned from grandparents
- **Under 25:** Approximately 13% of fluent speakers; growing, driven by bilingual education and cultural revival; the first generation among whom Zopikí is again being transmitted intergenerationally in some highland communities

- Universidad Nacional de Zoopaná (UNZ): Zopikí language courses since 1995; currently ~400 students/semester
- Universidad de la Sierra del Oeste (USO): the national center; ~600 students/semester in formal programs
- Cultural centers, community organizations: ~800 participants in informal classes nationally
- Online courses and apps (since 2018): estimated 6,000–8,000 active users of the *ZopikíApp* (developed by the Academia Zopikí in partnership with the MECC)

## SECTION 7: WRITING SYSTEM AND ORTHOGRAPHIC HISTORY

### 7.1 Colonial-Era Writing

The first written Zopikí dates to approximately **1670–1680**, produced by Jesuit missionaries. Two significant colonial-era written records exist:

1. **Misión de Nuestra Señora de la Paz de Zupakka records** (Zoopaná mission, Father Gerónimo de Arrieta SJ, ca. 1680): A partial transcription of the *Marán-kati* oral epic, covering eleven episodes, in a mixed Zopikí-Spanish manuscript now held in the Convento de San Francisco. This manuscript used a proto-orthography derived from Spanish letter-values with a few invented diacritics for sounds without Spanish equivalents.

2. **Misión de Santa María del Pequeé school documents** (Pequeé Norte mission, Father Alonso de Vargas SJ, ca. 1670): Partial transcription of the *Tupana Inti-kama* epic with Spanish interlinear translation. These documents are in the Vatican archives (partially repatriated on microfilm to the Archivo Nacional de Zoop in 1991).

The colonial orthographies were inconsistent and untrained — different missionaries spelled the same words differently (e.g., the word *kanatl* appears as *canatl*, *canatil*, *quanatl*, and *kkanatl* in different sources). No standardized colonial Zopikí orthography was ever established.

### 7.2 The Academia Zopikí and the 1998 Standard

The modern standard orthography of Zopikí was established by the **Academia Zopikí (AZ)** — a body created by the **Ministerio de Educación, Ciencia y Cultura (MECC)** under the terms of the **Ley de Educación Intercultural Bilingüe (LEIB, 2001)** — but the preparatory work for the orthography was done earlier, during the 1994–1998 period of post-constitutional organization.

The standard was published in **1998** as the **Ortografía Oficial del Zopikí** (OOZ). It uses a modified Latin alphabet with the following specific conventions:

**The Ortografía Oficial del Zopikí (OOZ, 1998):**
- **kk** = geminate velar stop; always word-final (never medial in native words); retained in *Zupakk* as a historical form
- **ch** = palatal affricate /tʃ/ (always; never /ʃ/)
- **z** = voiced fricative /z/ (always voiced; never /s/)
- **tl** = word-final relational nominalizer cluster; written as two letters even though pronounced as syllabic lateral
- **-é** = long /eː/ vowel (used only in *Pequeé* and related forms as a historicism; modern Zopikí has essentially completed the vowel merger)
- **Acute accent on other vowels** = long vowels (rare; primarily in *marán*)
- **Hyphen** = used in compounds to show the boundary between the noun root and its modifier (*kanatl-pela*, *Inti-Zupaka*)

**The Academia Zopikí (AZ):**
- Founded: 1996 under the MECC, two years after the 1994 Constitution
- Composition: 12 members — 6 native-speaker linguists and community elders, 3 academic linguists from USO and UNZ, 2 representatives of the Movimiento Zopikí (MZ), 1 MECC appointee
- Function: Maintains the OOZ; advises on new loanwords (particularly scientific and technological vocabulary); reviews bilingual education materials; arbitrates spelling disputes
- Headquarters: Cerro Verde, Provincia de Pequeé Norte (deliberately located in the heartland of the highest-density Zopikí-speaking area, not in the capital)
- First president: **Dr. Fortunata Yahuar Quispe** (USO; served 1996–2008)
- Current president: **Prof. Héctor Mamani Tupani** (b. 1965, Las Cumbres; USO; served 2008–present)

**Competing orthography:** A smaller community of Zopikí speakers and scholars, primarily from Los Esteros province, use the **Ortografía del Marán Bajo** (Low Marán Orthography, OMB) — an alternative system developed in 1991 by community linguist **Rosario Esterotl Canela** (b. 1958, Los Esteros) that reflects the phonological features of the Los Esteros dialect more precisely. The OMB uses *q* for the geminate and does not use hyphens in compounds. The two systems are mutually intelligible in writing; the AZ's OOZ is used in all government and educational materials.

## SECTION 8: CO-OFFICIAL STATUS AND LEGAL FRAMEWORK

### 8.1 The 1994 Constitution

Zopikí was recognized as **co-official language of the República de Zoop** by the **1994 Constitution** (Article 12): *"The Republic of Zoop recognizes Zopikí as a co-official language of the state, alongside Spanish. In provinces with significant Zopikí-speaking populations, public institutions shall provide services in Zopikí upon request."*

The co-official status was a direct result of political negotiation between the center-left **Frente Popular Zoopano (FPZ)** government of President Fernando Briceño Lemus (#28, 1993–2001) and the **Movimiento Zopikí (MZ)** — which won 7 seats in the Chamber of Deputies in the 1993 elections and conditioned its legislative support on language recognition.

### 8.2 What Co-Official Status Means in Practice

**What the law requires:**
- Government documents must be available in Zopikí upon request in the four Sierra del Oeste provinces (Pequeé Norte, Las Cumbres, Río Hondo, Valles del Oeste)
- Court proceedings: any person may request Zopikí interpretation in any court in the country; the state must provide a certified interpreter within a reasonable time (the Ley de Acceso a la Justicia Bilingüe, 1997, defines "reasonable time" as 72 hours for non-emergency proceedings)
- Legislative proceedings: any member of the Congreso Nacional may address either chamber in Zopikí; the Secretaría General must provide simultaneous Spanish translation
- National monuments, signs, and official communications in the four target provinces must be bilingual (Spanish/Zopikí) by a 2006 decree

**What the law does not require:**
- All government documents in the country to be in Zopikí (only upon specific request in the target provinces)
- Spanish-speaking citizens to know Zopikí
- Federal agencies based in Zoopaná to operate in Zopikí (though the MECC and the Ministry of Culture have Zopikí-speaking offices)

**Interpretation in practice:** The court interpretation right is the most exercised legal provision. The Defensoría del Pueblo (national ombudsman office) reports approximately 340 court interpretation requests per year, up from 47 in 1998. Most are in the Sierra del Oeste provinces; a growing minority are in Zoopaná and Puerto Marán (reflecting urban migration of indigenous speakers).

### 8.3 The Provincial Co-Official Framework

By provincial decree, Zopikí has **full co-official status** (not just upon request) within:
- **Provincia de Pequeé Norte** (decree 2002): all provincial government communications in both languages
- **Provincia de Las Cumbres** (decree 2005): all provincial government communications in both languages
- **Provincia de Río Hondo** (decree 2009): provincial communications in both languages in highland communities; Spanish-primary in the provincial capital Hondo

## SECTION 9: BILINGUAL EDUCATION

### 9.1 The LEIB Program

The **Ley de Educación Intercultural Bilingüe (LEIB, 2001)** established the framework for bilingual Spanish-Zopikí education. Implementation has been progressive:

**Current enrollment (2024):** Approximately **48,000 students** in bilingual Spanish-Zopikí primary education programs

**Provincial breakdown:**
| Province | Enrolled Students | % of Province Primary Enrollment |
|---|---|---|
| Pequeé Norte | 22,000 | 61% |
| Las Cumbres | 11,000 | 47% |
| Río Hondo | 8,000 | 39% |
| Valles del Oeste | 7,000 | 28% |
| **Total** | **48,000** | |

### 9.2 How the Bilingual Program Works

**Curriculum model:** Zoop uses an **additive bilingualism** model — Zopikí is taught as a full language of instruction alongside Spanish, not merely as a subject. In grades 1–4, approximately 40% of instruction is in Zopikí; in grades 5–7, this reduces to 25% to ensure Spanish proficiency for secondary school. Core subjects taught in Zopikí include: oral literature and cultural studies, local history and geography, and — in higher-immersion schools — mathematics.

**The Colegio Intercultural Bilingüe Anuyán model:** The first fully bilingual secondary school, the **Colegio Intercultural Bilingüe Anuyán** (named for independence-era Zopikí leader Cacique Anuyán), opened in Cerro Verde in 2020 with 340 students. It offers the full secondary curriculum with 30% of instruction in Zopikí. As of 2024, it has 620 students and a waiting list. Plans exist to replicate the model in San Ignacio de las Cumbres and Hondo.

### 9.3 The Teacher Shortage

The primary structural problem for the bilingual program is the shortage of qualified teachers who are both fluent in Zopikí and trained in bilingual pedagogy.

- **Current qualified bilingual teachers:** ~380 (as of 2024)
- **Estimated need for full provincial coverage:** ~650
- **Shortage:** ~270 teachers
- **Training program:** The USO runs a **Programa de Formación Docente Bilingüe** (Bilingual Teacher Training Program) that has graduated approximately 180 bilingual teachers since 2010, at a rate of approximately 20 per year. The Carballo government's education reform proposal aims to triple the annual graduation rate by establishing a dedicated national teacher training center at the USO.

**Why the shortage is hard to fix:** Native speakers who are qualified to teach are disproportionately older; younger fluent speakers are often attracted to better-paying professions; the teacher salary premium for bilingual instruction is only 12% above the standard rate, which is insufficient to compensate for the extended training period.

## SECTION 10: LANGUAGE REVIVAL AND CULTURAL INSTITUTIONS

### 10.1 The Revival Movement

The Zopikí language revival traces two distinct threads:

**Thread 1 — Community-based revival (pre-1994):** In highland communities of Pequeé Norte and Las Cumbres, Zopikí was never fully suppressed even during the Years of Lead; it was transmitted privately in homes and in the context of traditional religious ceremonies (the yatiris continued to use Zopikí in ceremonies even when public use was dangerous). This thread represents continuity, not revival.

**Thread 2 — Institutional and urban revival (post-1994):** The 1994 Constitution's recognition was the catalyst for an institutional revival: the founding of the Academia Zopikí (1996), the LEIB program (2001), the bilingual education expansion, and the growing urban Zopikí movement. This thread is genuinely revivalist — it includes urban-born Zoopans with no heritage speaking who are learning the language as a political and cultural act.

### 10.2 Key Organizations

**Academia Zopikí (AZ)**
- Founded 1996; see Section 7.2 for full description
- Location: Cerro Verde (headquarters) with an office in Zoopaná

**Centro de Estudios Zopikí (CEZ-USO)**
- Location: Universidad de la Sierra del Oeste, Cerro Verde
- Function: Primary academic research center for Zopikí language documentation, ethnography, and traditional ecological knowledge
- Director: **Dr. Renato Mamani Cori** (b. 1964, Las Cumbres; also the scholar who compiled the modern reconstruction of the *Tupana Inti-kama* cycle in 1998)
- Key publication: *Anuario de Lingüística Zopikí* (founded 2004; annual academic journal)

**Consejo de Yatiris de Zoop (CYZ)**
- Founded 1997, Cerro Verde; traditional practitioners' organization; maintains oral archive of ceremonial knowledge; advocates for sacred site protection; holds annual gathering every July at Confluencia

### 10.3 Radio Zopikí (104.5 FM)

**Radio Zopikí** operates at **104.5 FM** from Cerro Verde (Provincia de Pequeé Norte). It is the only Zopikí-language radio station in the country and a cornerstone of the language revival effort.

- **Founded:** 1999, by the Asociación Cultural Zopikí del Oeste (ACZO), with partial funding from the MECC's Cultural Diversity Fund
- **Signal reach:** Cerro Verde urban area and surrounding municipalities; streamed online nationally and internationally since 2008
- **Programming:** 14 hours per day in Zopikí; 10 hours in bilingual Spanish-Zopikí. Programming includes: traditional music (quena, siku, bombo, antara), oral literature readings (including the three epic cycles in full during annual broadcasts), news in Zopikí, youth programs, and language-learning segments (*Aprende Zopikí*, 30 minutes daily)
- **Audience:** Approximately 18,000 regular listeners in signal range; online streaming draws an additional 4,000–6,000 listeners/day, including diaspora communities in Zoopaná, Puerto Marán, Buenos Aires, and Santiago

### 10.4 Digital Media and the *ZopikíApp*

The **ZopikíApp** — a language-learning application for Zopikí — was developed by the Academia Zopikí in partnership with the MECC, launched in 2018. As of 2024, it has approximately 34,000 registered users, of whom approximately 6,000–8,000 are active users (logged in within the past 30 days). The app provides: vocabulary flashcards, pronunciation audio (recorded by native speakers from Pequeé Norte and Las Cumbres), grammar explanations, and conversational practice dialogues. A children's version (*ZopikíApp Infantil*) was released in 2021 and is used in some bilingual classrooms.

Social media presence: A Zopikí-language content creator community has developed on Instagram and TikTok since approximately 2020 — predominantly young highland creators posting short videos in Zopikí about daily life, traditional food preparation, and cultural practices. The hashtag #ZopikíVivo ("Zopikí alive") has accumulated over 2 million posts as of 2024.

### 10.5 The Festival Zopikí (Annual Cultural Festival)

The **Festival Zopikí** is the annual celebration of Zopikí language and culture, established in 1996 by the Academia Zopikí and the Movimiento Zopikí.

- **When:** Second weekend of August — the same period as the Fiesta de la Pachamama Zoopana, which the festival accompanies and amplifies
- **Where:** Cerro Verde (the primary venue, hosting the main stage and oral literature performances); satellite events in San Ignacio de las Cumbres, Hondo, and (since 2015) in Zoopaná's Parque de las Naciones
- **What happens:** Three days of Zopikí oral literature performance (including full performances of episodes from the three epic cycles); traditional music and dance; artisan markets; bilingual literary readings; the annual award of the **Premio Zopikí de Literatura** (an award for the best new work published in or about Zopikí during the year); yatiri ceremonies (open attendance for the public portions, restricted for the sacred portions); children's language activities
- **Attendance:** Approximately 12,000 in Cerro Verde; 3,000–5,000 at satellite events. Growing annually since 2015.
- **National recognition:** Since 2018, the Festival Zopikí has been included in the national cultural calendar published by the MECC; the President of the Republic traditionally sends a written message that is read aloud in both Spanish and Zopikí on the festival's opening day

## SECTION 11: ORAL LITERARY TRADITION (CROSS-REFERENCE SESSION 6-A)

### 11.1 The Three Epic Cycles — Additional Detail

**1. *Marán-kati* ("Song of the Great River")**
- Communities: Zupakka and Marantika (river-basin communities)
- Primary occasion: *Tupana Marantl* (Festival of the River, late July) — performed in full over the multi-day festival
- Structure: ~40 distinct episodes; a trained *nakati* (speaker/voice-bearer) could perform 3–5 episodes per day; the complete cycle required 8–12 days of performance
- Performance style: Chanted in a specific ritual register of Zopikí (slower tempo, archaic vocabulary not used in daily speech); the nakati used a *katikana* cord as a mnemonic device during performance, touching specific knots at specific narrative moments
- Modern performance: Performed annually at the Bendición de las Aguas ceremony; full performance at the Festival Zopikí every three years (the "Gran Marán-kati" performance, considered a major cultural event); ongoing performances in highland community contexts

**2. *Tupana Inti-kama* ("The Sun's Covenant")**
- Communities: Tupanachi and Pequeéka (highland communities)
- Primary occasion: *Tupana Inti* (Festival of the Sun, June solstice); specifically the highland community of Tupanachi Alto near San Ignacio de las Cumbres maintains the most complete performance tradition
- UNESCO status: Intangible Cultural Heritage candidate (application submitted 2018; decision pending as of 2024)
- Modern performance: The Fiesta de San Juan Dorado (24 June) in highland provinces includes partial performance of episodes from *Tupana Inti-kama*; the complete cycle is performed every five years at the community of Tupanachi Alto

**3. *Pachatika-kama* ("The Earth Giver's Teaching")**
- Communities: Pachakama and Bartomaca (agricultural and river-fork communities)
- Structure: ~28 distinct teachings (shorter than the other two cycles; parabolic rather than narrative-epic in form)
- Primary occasion: *Tupana Tika* (Festival of the Harvest) and the Fiesta de la Pachamama Zoopana (August)
- Educational role: The most accessible of the three cycles; used in primary school bilingual education as the first introduced; adapted by contemporary writers (Calderón Ríos drew on it in *El último kanatl*)

## SECTION 12: DIALECTAL VARIATION

Zopikí is not a single undifferentiated language; it has three principal dialect groups, corresponding roughly to the historical community territories:

**1. Lowland Marán dialect** (*Zupakí del Marán*)
- Spoken by Zupakka-, Marantika-, and Pachakama-heritage communities
- Geographic range: Río Marán basin; Llanuras del Centro; Los Esteros
- Characteristics: More borrowing from Spanish; simplified consonant clusters (the *-tl* suffix is often realized as *-l* or *-t*); fuller vowel system (some speakers distinguish /e/ and /o/ as separate vowels, a Spanish-influenced innovation); the prestige dialect for written Zopikí

**2. Highland Pequeéka-Tupanachi dialect** (*Zupakí del Oeste*)
- Spoken by Pequeéka- and Tupanachi-heritage communities
- Geographic range: Sierra del Oeste; Pequeé Norte; Las Cumbres; Río Hondo
- Characteristics: More conservative; preserves more archaic vocabulary; maintains fuller *-tl* pronunciation; the *-é* vowel (long mid front) is preserved in the Pequeéka sub-variant; considered the most phonologically "pure" by traditionalists; the dialect on which the 1998 OOZ standard is primarily based
- The Pequeéka sub-variant has slightly different stress patterns (more consistent final-syllable stress) compared to the Tupanachi sub-variant

**3. Coastal and Wetland dialect** (*Zupakí del Río Bajo*)
- Spoken by Esterotl-heritage communities in Los Esteros
- Geographic range: Northeastern lowlands; wetland zones
- Characteristics: Most heavily influenced by contact with surrounding Spanish-speaking communities; some lexical innovations not found in highland dialect; the dialect documented by Rosario Esterotl Canela's competing Ortografía del Marán Bajo (OMB, 1991)
- The smallest dialect community in absolute numbers; maintained primarily among the oldest speakers in Los Esteros province
